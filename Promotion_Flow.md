# 🧱 Promotion Flow

This document describes the process of class promotion in the SRPG system.

---

## 🔄 Promotion Flow Overview

```text
Check Promotion Eligibility
↓
Is Unit Level Max?
↓
Has Promotion Item?
↓
Choose New Class (if branching)
↓
Update Stats and Class Tier
↓
Unlock New Class Skills
↓
Promotion Complete
```

---

## 🧩 Promotion Requirements

- Unit must reach **level cap** (usually Lv 20)
- Must possess appropriate **promotion item** (e.g., Master Seal)
- May be restricted by storyline or special flags

---

## 📘 Promotion Path Example

| Base Class   | Promotion Class |
|--------------|-----------------|
| Knight       | General          |
| Mage         | Sage             |
| Thief        | Assassin         |
| Pegasus Knight | Falcon Knight  |

---

## 🧠 Promotion Effects

| Effect                | Description                              |
|------------------------|------------------------------------------|
| Class Change           | New class name and tier                  |
| Stat Boost             | Instant bonus to core stats              |
| Weapon Access          | May gain access to new weapon types      |
| Skill Unlock           | Unlock class-based active/passive skills |
| New Cap Limits         | Max stat caps increase per tier          |

---

## 🎓 Skill Unlock Example

| Class Tier | Skill Unlocked     |
|------------|--------------------|
| Tier 2     | Brave Heart        |
| Tier 3     | Rally Defense      |
| Tier 4     | Sword Focus        |
| Tier 5     | Godstrike (Ultimate)|

---

## ❗ Notes

- Some classes may have **multiple promotion paths**
- Promotion cannot be undone
- Promotion may also change appearance, movement type, and base growth rates
