# 🎒 Inventory Management UI

Outlines the inventory system structure and user interactions.

---

## 📐 Inventory Limits

- Max 10 items per character
- Only 1 item per gear slot (weapon, armor, accessory)
- Consumables have quantity

---

## 🖱️ User Actions

| Action         | Description                      |
|----------------|----------------------------------|
| Equip          | Select weapon or gear to equip   |
| Use            | Use healing/buff item            |
| Trade          | Transfer item to adjacent unit   |
| Discard        | Drop item if inventory full      |
| View Details   | View stats and effects           |

---

## 🧩 UI Elements

- Item list grid
- Detail pane on hover/click
- Equipment slots visual (e.g. sword icon)
- Action menu popup

---

📌 Design for speed + clarity during battle
